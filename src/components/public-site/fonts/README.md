# Public typography

Barlow (400, 500, 600) and Barlow Semi Condensed (500, 600), by Jeremy Tribby.
Latin WOFF2 subsets, self-hosted with `next/font/local` on the public surfaces only.
Includes Spanish and Catalan characters. Total font assets: approximately 110 KB.

Source: [Fontsource Barlow](https://fontsource.org/fonts/barlow) and
[Barlow Semi Condensed](https://fontsource.org/fonts/barlow-semi-condensed), downloaded
2026-11-08 from `https://cdn.jsdelivr.net/fontsource/fonts/{family}@latest/latin-{weight}-normal.woff2`.
